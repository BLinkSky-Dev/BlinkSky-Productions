# Service category photos

Each shoot type has its own folder:

  wedding/
  bridal/
  model/
  casual/
  birthday/
  commercial/
  graduation/

Drop JPGs/PNGs/WebPs into the matching folder (prefer 01.jpg, 02.jpg, …).
01.jpg is used as the accordion thumb / cover.

Then run from the project root:

  npm run gallery:refresh
